## 📌 Overview

CivicTrack is a full-stack civic engagement web application that empowers citizens to report societal problems directly to government authorities. The platform automatically assesses the urgency of each complaint and routes it to the appropriate government department — while keeping citizens informed with real-time status updates throughout the resolution process.

**Problem it solves:** In many communities, citizens have no structured, transparent channel to communicate infrastructure issues, safety concerns, or service failures to their local government. CivicTrack digitizes this process — making governance more responsive and accountable.

---

## ✨ Features

- **Complaint Submission** — Citizens submit issues with descriptions, location, and category
- **Urgency Detection** — Automatic classification of complaint priority (Low / Medium / High / Critical)
- **Government Dashboard** — Officers view, manage, and update complaint statuses
- **Real-time Updates** — Citizens receive status notifications as their complaint progresses
- **Case Tracking** — Full complaint lifecycle from submission to resolution
- **Responsive Design** — Fully optimized for mobile and desktop

## 🚀 Getting Started

### Prerequisites
- Node.js v18+
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/Ineza-Sonia/Complaint-Management-System.git
cd Complaint-Management-System

# Install dependencies
npm install

# Run development server
npm run dev
```

The app will be running at `http://localhost:5173`

### Build for Production

```bash
npm run build
```
